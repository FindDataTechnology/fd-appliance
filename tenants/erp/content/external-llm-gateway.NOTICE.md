# 公网大模型网关 — 不入包（cloud_locked）

- 组件分类：cloud_locked，严禁随整机包出包（vertical-appliance-delivery 可私有化不变量）。
- 原因：该网关依赖公网 SaaS 大模型服务，客户机房断网环境下不可用；包内不得含任何
  公网硬地址 / 云厂商专属服务依赖。
- 替代（substitute）：客户自带内网 LLM 网关，装后配置；BYOK 凭证经环境变量注入
  运行进程，零落库零日志，我方不代持、不运输、不存储。
- 与内核关系：ERP 账本内核 32 个工具面（拟稿 / 落账 / 事件 / 过账 / 对账 / 查询）全部在本地库离线闭环，
  不调用此网关；AI 辅助层为可选叠加，缺失时内核能力不降级为不可用。
- 任何外部模型 / 网关端点均为客户内网地址，本包不含任何公网硬地址或 IP。
